# 🦸 Felipão Challenge — Hero Level Classifier

[🇧🇷 Português](README.md) | 🇺🇸 English | [🇪🇸 Español](README.es.md)

> A programming logic exercise inspired by DIO's **Hero Level Classifier** challenge.

## 🎯 Objective

Create a JavaScript application that receives a hero's experience value and determines their level according to predefined XP ranges.

## 🧠 Concepts practiced

- Variables
- Conditional structures
- Relational operators
- Template strings
- Basic code organization

## 📊 Levels

| XP | Level |
|---|---|
| Less than 1,000 | Iron |
| 1,001–2,000 | Bronze |
| 2,001–5,000 | Silver |
| 5,001–7,000 | Gold |
| 7,001–8,000 | Platinum |
| 8,001–9,000 | Ascendant |
| 9,001–10,000 | Immortal |
| 10,001 or more | Radiant |

## ▶️ How to run

With Node.js installed:

```bash
node src/index.js
```

## 🚀 Example

```text
The hero named Felipão is at the Ascendant level
```
