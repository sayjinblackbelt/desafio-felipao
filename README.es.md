# 🦸 Desafío Felipão — Clasificador de Nivel de Héroe

[🇧🇷 Português](README.md) | [🇺🇸 English](README.en.md) | 🇪🇸 Español

> Ejercicio de lógica de programación inspirado en el desafío **Clasificador de Nivel de Héroe** de DIO.

## 🎯 Objetivo

Crear una aplicación en JavaScript que recibe la experiencia de un héroe y determina su nivel según rangos predefinidos de XP.

## 🧠 Conceptos practicados

- Variables
- Estructuras condicionales
- Operadores relacionales
- Template strings
- Organización básica del código

## 📊 Niveles

| XP | Nivel |
|---|---|
| Menor que 1.000 | Hierro |
| 1.001–2.000 | Bronce |
| 2.001–5.000 | Plata |
| 5.001–7.000 | Oro |
| 7.001–8.000 | Platino |
| 8.001–9.000 | Ascendente |
| 9.001–10.000 | Inmortal |
| 10.001 o más | Radiante |

## ▶️ Cómo ejecutar

Con Node.js instalado:

```bash
node src/index.js
```

## 🚀 Ejemplo

```text
El héroe llamado Felipão está en el nivel Ascendente
```
